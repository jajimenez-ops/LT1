
# How to calculate the area, circumference, and square root with only the radius
## The problem is the garden
## We decompose it into 3 parts , "What's the radius," "What's the circumference," and "What is the square root of the area."
## We run the program using the CircularGarden.py file
## The input needed for the program to run is the radius in ***METERS***.
## Example:
### Input : 7
### Area : 153.94 meters
### Circumference of the garden : 43.98 meters
### The square root of the area : 12.41
### Area rounded down: 153 square meters
### Area rounded up : 154 square meters
